# Cover Letters

Generated cover letters live here, one file per application.

**Naming:** `cover_<company-slug>_<role-slug>.md`
e.g. `cover_moffitt_specimen-processing-supervisor.md`

**How to create one:**
1. Open `/prompts/cover_letter_prompt.md`.
2. Paste it into Claude with the job description.
3. Save the output here using the suggested filename.
4. Record the filename in the tracker's **Cover Letter Used** column.

A ready template is provided in `_TEMPLATE.md`.
